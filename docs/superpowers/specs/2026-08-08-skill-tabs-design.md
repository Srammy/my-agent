# Skill 标签合并设计

## 目标

将右侧的 `Skill` 与 `Skill 审核` 合并为一个顶层 `Skill` 标签，减少右侧顶层导航项，并保留两类功能的独立入口。

## 界面结构

```text
Skill
├── 我的skill
└── 自进化skill审核
```

- 右侧辅助面板只显示一个顶层标签：`Skill`。
- `Skill` 内容区域内显示两个子标签：`我的skill`、`自进化skill审核`。
- 默认打开 `我的skill`，保持当前 Skill 列表的使用路径。
- “上传”和 Skill 删除等现有操作继续放在 `我的skill` 子标签中。
- 审核列表及批准、拒绝等现有操作继续放在 `自进化skill审核` 子标签中。
- 权限选择器继续位于对话输入框右侧，不参与此次改动。

## 实现边界

- 只调整 `ChatView` 的标签层级和对应测试。
- 复用现有 `SkillPanel`、`SkillReviewPanel`，不改变数据接口、状态管理或审核逻辑。
- 不新增路由、不修改后端、不改变 Skill 内容。

## 验证标准

- 顶层存在 `Skill`，不存在独立的 `Skill 审核` 顶层标签。
- 两个子标签文字准确为 `我的skill` 和 `自进化skill审核`。
- 两个子面板都能正常渲染，默认显示 `我的skill`。
- 前端现有测试及新增标签结构测试全部通过。

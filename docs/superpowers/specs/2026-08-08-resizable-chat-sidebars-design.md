# 聊天侧栏可拖拽宽度设计

## 目标

在桌面三栏布局中，让左侧会话栏和右侧辅助面板可通过与聊天区之间的垂直分隔条左右拖拽调整宽度，并在刷新页面后恢复。

## 交互

- 左右面板各有一条可拖拽分隔条，鼠标和触摸指针均可操作。
- 左侧宽度限制为 220–420px，右侧限制为 280–500px；聊天主区始终至少保留 420px。
- 拖拽过程中显示 `col-resize` 光标并禁用文本选择；松开或取消指针后恢复。
- 宽度保存到浏览器 `localStorage`，页面重新加载时恢复有效数值。

## 布局与兼容性

- 宽度通过 `ChatView` 的 CSS 自定义属性驱动现有三栏 grid。
- 仅在视口宽度大于 1180px 时渲染与启用分隔条。
- 1180px 及以下保持既有双栏或单栏响应式布局，不读取拖拽宽度参与排版。

## 验证

- 添加 `ChatView` 组件测试，验证已保存宽度被恢复，以及拖拽更新并持久化对应宽度。
- 运行相关前端测试、类型检查和生产构建。
